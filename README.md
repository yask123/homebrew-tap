# yask123/tap

Homebrew casks and formulae by [@yask123](https://github.com/yask123).

```bash
brew install yask123/tap/<name>
```

| Name | Kind | Description |
|---|---|---|
| [pulse](https://github.com/yask123/pulse) | cask | Menu bar system monitor for Apple Silicon Macs |
| [mono-safari](https://yask.dev/mono) | cask | Quiet, terminal-style reading view for X in Safari |
| [mono-chrome](https://yask.dev/mono) | formula | The same, for Chrome, Arc, Brave and Edge |
